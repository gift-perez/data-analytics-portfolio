# 🐍 Python E-Commerce Supply Chain & Logistics Pipeline

## 📋 Overview

This project features an automated Python ETL pipeline built with `pandas` and `seaborn` to process multi-table e-commerce data from the Olist Brazilian dataset. It cleans timestamps, computes logistics performance metrics (such as delivery delay duration vs. estimated windows), aggregates regional fulfillment bottlenecks, and outputs automated CSV reports and visual charts.

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Libraries:** `pandas`, `numpy`, `matplotlib`, `seaborn`
- **Workflow:** Automated ETL script processing raw multi-table relational CSVs into structured analytics.
